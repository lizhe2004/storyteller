# 音色管理页面设计

## 背景与目标

新增一个音色管理页面，展示所有已加载的 TTS 音色，支持按 provider、模型、性别和年龄过滤；用户可以修改音色的年龄范围，并直接试听故事生成过程中已经保存的角色台词音频片段。

内置 `voices.json` 保持只读。年龄修改保存到 `data_dir` 下的独立覆盖文件，使修改能跨重启保留，并适用于 Docker 环境和后续镜像升级。

## 范围

### 包含

- 阿里云和火山引擎等已注册 TTS provider 的全部音色。
- 音色的 provider、模型、voice ID、名称、性别、年龄、分类和描述。
- provider、模型、性别、年龄组合过滤。
- 年龄字段的单选/多选编辑和持久化。
- 故事生成过程中保存的角色台词音频片段列表和播放。
- 登录保护、旧项目兼容和音频路径安全校验。

### 不包含

- 不修改内置 provider 音色库 JSON。
- 不使用或展示音色分析任务的 samples 作为试听片段。
- 不在管理页重新调用 TTS 生成试听音频。
- 不修改历史故事音频，只修改当前音色元数据覆盖。

## 核心身份模型

`VoiceConfig` 增加可选 `model` 字段。provider 实现负责填充该字段：

- 阿里云：使用 catalog 记录的 `model`。
- 火山引擎：使用 catalog 记录的 `resource_id` 作为模型身份。

音色唯一键为：

```text
provider + model + voice_id
```

所有音色覆盖、历史音频关联和 API 路径都使用该唯一键，避免不同 provider 或模型下的同名 voice ID 冲突。

## 年龄覆盖

覆盖文件位于：

```text
<data_dir>/config/voice-overrides.json
```

格式示例：

```json
{
  "aliyun|qwen-audio-3.0-tts-plus|longanlingxin": {
    "age": ["child", "teen", "young_adult"],
    "updated_at": "2026-09-24T12:00:00+08:00"
  }
}
```

读取音色库时，将覆盖值叠加到内置 catalog；内置数据不被写回。年龄值只允许：

```text
child, teen, young_adult, middle_aged, senior
```

保存时去重并保持标准年龄顺序。空数组允许表示未知年龄。非法值返回 400，文件写入采用临时文件替换，避免写入中断造成损坏。

## `VoiceConfig` 与历史数据兼容

- 新生成的角色和台词 `voice_config` 持久化 `model`。
- 读取旧 `project.json` 时，如果没有 `model`，通过当前 provider catalog 的 `provider + voice_id` 回填。
- 无法唯一回填时保留原始配置，并将模型标记为未知；该音频仍可被展示，但不会错误归入其他模型。
- 年龄覆盖只影响当前 catalog 和后续角色匹配，不改写历史项目中的角色/台词配置。

## 故事音频聚合

后端扫描 `project_dir` 下已保存的故事项目：

1. 读取项目的 `script.lines`。
2. 找到每条台词的 `voice_config`。
3. 根据 `line_id` 检查项目目录下的 `audio/<line_id>.mp3`。
4. 用音色唯一键将片段归入对应音色。
5. 返回故事标题、项目 ID、角色名、台词文本、生成时间、音频文件名和时长。

音色分析任务的 samples 不进入这个聚合结果。音频播放接口只允许返回项目目录内部、已登记的台词音频，禁止通过请求参数访问任意文件。

## API

### `GET /api/voices`

返回全部音色及可选过滤条件：

- `provider`
- `model`
- `gender`
- `age`

每项返回基础元数据、年龄覆盖状态、是否有故事片段及片段数量。列表接口支持分页，避免一次返回所有历史片段；片段通过详情接口加载。

### `PATCH /api/voices/{voice_key}`

请求体：

```json
{"age": ["child", "teen"]}
```

校验并保存年龄覆盖，返回更新后的音色信息。

### `GET /api/voices/{voice_key}/clips`

返回该音色对应的故事台词片段列表，按生成时间倒序。

### `GET /api/voices/{voice_key}/clips/{clip_id}/audio`

返回已存在的台词 MP3，沿用现有登录认证和安全响应头。

所有接口均要求登录。

## 前端页面

新增 `/voices` 页面和导航入口。

- 顶部提供 provider、模型、性别、年龄筛选器。
- 列表展示所有音色；没有历史片段的音色显示“暂无故事试听片段”。
- 音色详情展开后展示年龄 checkbox 多选编辑、保存操作和历史故事台词片段。
- 片段使用原生 audio 控件播放，并显示故事、角色和台词文本。
- 保存成功后更新当前卡片，不清空筛选条件；失败时保留原值并显示错误。

## 错误处理与性能

- provider 或音色不存在返回 404。
- 年龄值非法返回 400。
- 片段不存在或路径不安全返回 404/400。
- 项目文件损坏时跳过该项目并记录警告，不阻塞整个列表。
- 第一版在请求时扫描项目目录；如果项目数量造成响应变慢，再引入基于项目修改时间的缓存或索引。
